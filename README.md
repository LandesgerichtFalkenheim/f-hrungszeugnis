# Führungszeugnis Generator

Ein kleines Node.js‑System zum Erstellen von Führungszeugnissen aus einer PDF‑Vorlage.

## Funktionen
- Formular zur Eingabe aller Daten
- Automatische Sicherheitsnummer
- Sicherheitsnummer wird im Archiv hexadezimal gespeichert
- PDF‑Erstellung über pdf-lib
- Archiv aller ausgestellten Dokumente
